## 4. SERVICIOS / CÓMO TRABAJAMOS

Servicios acotados. Registro: declarativo, no lista de buzzwords.

**Qué hacemos**
- ES: Diseñamos y construimos sitios web. Editoriales, rápidos, y pensados para vender — no solo para verse bien.
- EN: We design and build websites. Editorial, fast, and made to sell — not just to look good.

**Cómo trabajamos** (los 4 pasos — el copy actual está bien, se ajusta el tono)
1. **Discover / Entender** — Entendemos el negocio, el cliente y el mercado antes de diseñar nada.
2. **Direction / Dirección** — Definimos posicionamiento, estructura y dirección visual. Cada decisión apunta al mismo lado.
3. **Build / Construir** — Construimos el sitio. Responsive, rápido, listo para buscadores.
4. **Launch / Lanzar** — Probamos todo y lo publicamos listo para funcionar, no solo para existir.
